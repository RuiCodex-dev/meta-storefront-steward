Approval queue

Two kinds of work wait here. Replies: Muse Spark drafts each one in the reviewer's language; a deterministic verifier blocks drafts that are too long, in the wrong language, promise dates or refunds, contain personal data or cite something that does not exist, and a blocked draft goes back to the model once with the verifier's findings. Engineering tickets: written from the issue's evidence; the verifier rejects any app, version or id that is not in that evidence. Nothing reaches a store or a tracker without an approval click{% if not live() %}, and this process is in dry-run mode{% endif %}.
